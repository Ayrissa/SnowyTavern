# ❄️ SnowyTavern

Новогодний/рождественский эффект снега для SillyTavern: снежинки падают
поверх интерфейса и оседают внизу экрана. Снег можно стряхнуть движением
мыши, скатать в снежок, а из пары снежков собрать снеговика — прямо на
экране, поверх чата.

Плюс опциональная лёгкая праздничная тема оформления интерфейса (цвета,
акценты), которая включается/выключается независимо от снега.

## Возможности

- **Падающий снег** — лёгкие снежинки падают сверху и оседают по нижнему
  краю экрана слоем, который растёт со временем.
- **Стряхивание** — проведи мышью по осевшему снегу, и он разлетится в
  стороны мелкими частицами.
- **Снежки** — зажми кнопку мыши на снегу и потяни: снег соберётся в
  растущий ком. Чем дольше тащишь по снегу, тем он больше.
- **Снеговик** — поднеси готовый снежок к другому (или брось крупный
  снежок отдельно), и снежки сложатся в снеговика из трёх шаров.
- **Настройка интенсивности** — слайдер в настройках расширения управляет
  частотой снегопада и скоростью накопления снега (от лёгкой измороси до
  плотной метели).
- **Праздничная тема** — отдельный переключатель, который красит акценты
  интерфейса (скроллбар, кнопки, рамки) в рождественские цвета, не трогая
  сам эффект снега.
- **Кнопка «Очистить снег»** — мгновенно убирает весь накопленный снег и
  снеговиков, если расширение начало тормозить интерфейс или просто
  захотелось чистого экрана.
